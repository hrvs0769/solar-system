# 视觉自检台（奔月场景专用）

这套脚本是「用眼睛验收」的落地工具：把电影模块的每一帧定格、按机位环绕拍摄、按时间采样成胶片，
再由人（或模型）逐张看。**只看平均亮度之类的指标会漏掉"画面里全是柱子"这种事故**，所以两个维度都要看。

## 脚本

| 脚本 | 作用 | 输出 |
| --- | --- | --- |
| `scripts/vision-audit.mjs` | 11 个阶段 × 7 个机位（导演机位 + 每 60° 环绕）定格拍摄，附像素统计，并生成每阶段接触表 | `shots/sheet_<阶段>.png`、`shots/sheet_ALL.png`、`shots/report.json` |
| `scripts/motion-strip.mjs <阶段> [帧数]` | 把某阶段按时间等分采样，拼成"胶片"，用来判断运镜与**节奏**（静止截图看不出快慢） | `shots/strip_<阶段>.png` |
| `scripts/perf-mission.mjs` | 逐阶段测帧时间 / draw call / 三角形数（默认走真实 GPU；`SW=1` 走软件渲染） | 控制台 |
| `scripts/verify-lunar.mjs` | 端到端验收：阶段序列、成功弹窗、收尾是否还原渲染设置、雾参数是否合法 | 控制台 |
| `scripts/mobile-check.mjs` | 手机竖屏视口加载 mobile.html，切 Tab、抓截图、看有没有报错 | `/tmp/mobile.png` |

常用组合：

```bash
npm run build:offline                      # 自检台默认跑 dist-offline
node scripts/vision-audit.mjs              # 全部阶段（约 7 分钟）
node scripts/vision-audit.mjs LANDING LOI  # 只拍指定阶段
node scripts/motion-strip.mjs TRANSFER 12  # 转移段 12 帧胶片
node scripts/perf-mission.mjs              # 真机帧率
```

## 页面侧接口（QA API）

`src/modules/lunar-mission.js` 里有一小组只为自检存在的方法，正常演示不会触发：

- `qaGoto(phase, frac)` —— 依次"预热"到该阶段的 `frac` 处并**定格**（`dt` 归零），
  同时把自由视角/OrbitControls 关掉，否则相机会被轨道控制器拉回自己的位置。
- `qaCam(pos, tgt, up)` —— 定格后接管相机，用来拍环绕机位。
- `qaRelease()` —— 解除定格。

`window.__SS` 上另有 `textureProgress()`（贴图仓库进度）、`THREE`（自检脚本里做向量运算）。

## 已知坑（都是踩过的）

1. **贴图没就绪就开拍**：地球/月球会拍成纯色球。自检台会先等 `textureProgress().loaded >= total`。
2. **环绕机位穿进建筑**：地面阶段仰角太低时，az60 机位会进到厂房内部。地面阶段仰角保持 22~26°。
3. **相机被 OrbitControls 抢走**：绕地球段会开放自由视角，`qaGoto/qaCam` 必须先关掉它。
4. **定格时相机的 Lerp**：`qaGoto` 直接把 `_cam` 设为导演机位再渲染，不能依赖插值（`dt=0` 时插值系数为 0）。
5. **画布取样不可靠**：WebGL 画布 `drawImage` 取像素偶尔会拿到上一帧，判断"某物体是否渲染"要用真实截图。
