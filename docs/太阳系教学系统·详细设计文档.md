```js
renderer.setAnimationLoop((now) => {
  const dt = Math.min((now - lastNow) / 1000, 0.1); lastNow = now;
  if (clock.running) clock.jd += clock.rateDaysPerSec * dt;      // ① 推进模拟时间（double）
  astro.setFrame(clock.jd);                                       // ② 缓存本帧天文数据

  uiThrottled.update();                                           // ⑥ 节流刷新 UI 数据
```

## 3. 坐标系、单位与时间（关键章节，实现前必须理解）

### 3.1 场景坐标系

- 右手系；**Y 轴向上 = 黄道北极**；X 轴指向 J2000 春分点（黄经 0°）；Z 轴使行星公转在俯视（+Y 向下看）时呈**逆时针**。
- 单位：**AU**（1 AU = 1 场景单位）。近景相机靠近行星时仍用 AU，配合相机相对原点保证 float32 精度。

### 3.2 astronomy-engine → 场景坐标转换链

> 注意：`HelioVector` / `GeoVector` 返回 **J2000 赤道系（EQJ）** 直角坐标，必须先经 `Astronomy.Ecliptic()` 转黄道，否则整个系统会整体倾斜约 23.4°。

```js
// sim/astro.js 核心转换
import { Astronomy, Body } from 'astronomy-engine';

const DEG = Math.PI / 180;

function eclipticToScene(edist /*AU*/, elon /*deg*/, elat /*deg*/) {
  const lat = elat * DEG, lon = elon * DEG;
  return {
    x: edist * Math.cos(lat) * Math.cos(lon),
    y: edist * Math.sin(lat),
    z: -edist * Math.cos(lat) * Math.sin(lon),   // 负号 → 俯视逆时针
  };
}

function helioEclipticScene(body, time) {
  const ecl = Astronomy.Ecliptic(Astronomy.HelioVector(body, time)); // {elat, elon, edist}
  return eclipticToScene(ecl.edist, ecl.elon, ecl.elat);
}

// 月球日心位置 = 地月质心日心位置 + 月球地心位置（同系相加后转场景）
function moonHelioScene(time) {
  const emb = Astronomy.HelioVector(Body.EarthMoon, time);   // 地月质心，EQJ
  const geo = Astronomy.GeoVector(Body.Moon, time);          // 月球地心，EQJ
  const v = { x: emb.x + geo.x, y: emb.y + geo.y, z: emb.z + geo.z }; // 仍是 EQJ
  const ecl = Astronomy.Ecliptic(v);
  return eclipticToScene(ecl.edist, ecl.elon, ecl.elat);
}
```

### 3.3 时间系统

| 项 | 规定 |
|---|---|
| 内部表示 | **JD（UTC 基准）**，double。换算：`jd = AstroTime.ut + 2451545.0`；反算 `date = new Date((jd - 2440587.5) * 86400000)` |
| 显示 | 本地时区 `YYYY-MM-DD HH:mm`，取自 `new Date()` 的本地方法；跳转输入按本地日期解释 |
| 钳制 | `[2415020.5, 2488070.0]`（1900-01-01 ~ 2100-12-31，VSOP87 安全域）。越界：钳制 + 中文提示「日期超出支持范围（1900–2100）」 |
| 倍速档 | 0（暂停）、1 分钟/秒、1 小时/秒、1 天/秒、1 周/秒、1 朔望月(29.53 天)/秒、1 年(365.25 天)/秒；UI 标注人话「1 秒 = 1 天」 |
| 单步 | ±1 小时、±1 天 |
| 跳转 | 日期输入 + 「回到今天」按钮 |

### 3.4 渲染精度策略（R 级要求，P1 必须落地）

1. **相机相对原点**：所有天体挂载在 `root`（一个 `THREE.Group`）下；每帧 `root.position = -camera.position`。天体在场景内的局部坐标仍是 AU 量级？——否：天体位置每帧重算为**相对相机的双精度值**再赋给 `mesh.position`（three.js 内部转 float32 前先减相机，见下）。实现要点：

```js
// 每帧：把 double 黄道坐标转成“相对相机”的坐标再写入 three（避免 float32 大数）
const cam = camera.position; // 相机在黄道系中的位置（double 保存于 userData）
bodyMesh.position.set(px - cam.x, py - cam.y, pz - cam.z); // 双精度相减后数值很小
// root 本身保持 (0,0,0)；camera.position 同步置为 (0,0,0) 附近即可
```

   > 更稳妥的标准做法：`root.position.copy(camera.position).negate()` 每帧执行一次，天体位置按绝对黄道坐标写入。二者等效，任选其一，**但必须全场景统一**；验收：全景视角、海王星轨道最远处（30 AU）、暂停状态下行星无任何可见抖动。
2. **对数深度缓冲**：`new THREE.WebGLRenderer({ antialias: 按档, logarithmicDepthBuffer: true })`。
3. **自适应裁剪面**：每帧 `camera.near = max(1e-5, 0.01 * distToFocus)`；`camera.far = max(60, 12 * distToFocus)`（AU 单位）；`distToFocus` = 相机到最近关注天体（锁定目标或最近行星）的距离；`camera.updateProjectionMatrix()`。
4. 近景细节（行星贴图、土星环、大气）在行星局部几何内（半径 1e-2 AU 量级），相机相对原点后 float32 分辨率远小于像素级，无问题。

### 3.5 比例与可见性策略

| 模式 | 距离 | 行星视觉半径 | 太阳 | 月球 |
|---|---|---|---|---|
| 默认（教学） | 真实（1 AU=1） | 真实 ×300 | 真实 ×10 + 日冕精灵（视觉 ~×30） | 视觉轨道 0.04 AU（示意放大）、视觉半径 0.0016 AU |
| 月球真实比例 | 真实 | ×300 | 同上 | 真实地月距离 0.00257 AU（不可见，教学点） |
| 完全真实比例 | 真实 | ×1 | ×1（无日冕夸张） | 真实（不可见） |

- 行星视觉半径 ×300 后：水星 0.0049 AU ~ 木星 0.143 AU；土星环按行星半径比例缩放（内 1.24×、外 2.27× 行星视觉半径），视觉关系正确。
- 「示意」缩放处必须显示角标：主视图月球放大时在月球标签旁标注「月地距离已放大」；完全真实比例时全屏提示「真实比例：行星几乎不可见，这正是宇宙的尺度」。
- 行星自转：`rotationY = 2π·(jd − j2000)/P_sidereal + 相位`，P_sidereal 为恒星日（金星为负 = 逆向）；云层角速度 ×1.1。月球始终一面对地球：`rotationY = 月球公转经度`。

### 5.2 模拟时钟（sim/clock.js）

```js
// 状态
{ jd: number,           // 当前 JD（UTC 基），初始 = 今天
  rateDaysPerSec: 0,    // 0=暂停
  running: true }
// API
setRate(index)          // 0..6 → [0, 1min, 1h, 1d, 1w, 1synodicMonth, 1yr] 天/秒
step(hours)             // 单步 ±1h/±1d → jd += h/24，暂停并 emit clock.changed
jumpToDate(dateInput)   // 本地日期 → JD，钳制 §3.3，emit
backToNow()
tick(dt)                // running 时 jd += rateDaysPerSec*dt，钳制；每帧调用
getAstroTime()          // new Astronomy.MakeTime(jdToDate(this.jd))
```

JD↔Date 工具：`jdToDate(jd)`、`dateToJd(date)`（UTC 基准公式，见 §3.3）。钳制触发时 toast 提示（U2）。

### 5.3 天文封装（sim/astro.js）

| 函数 | 返回 | 说明 |
|---|---|---|
| `helioEclipticScene(bodyId, jd)` | {x,y,z} AU | §3.2 转换链；行星 + 太阳(0,0,0) |
| `moonHelioScene(jd)` | {x,y,z} AU | EMB + 地心月球，§3.2 |
| `moonGeoScene(jd)` | {x,y,z} AU | 地心黄道系（月相/潮汐模块用） |
| `getPhase(jd)` | { fraction 0..1, angle 0..360, name } | `Astronomy.Illumination(Body.Moon)`；name 按 §6.2.2 相位表映射 |
| `searchEclipses(fromJd, toJd)` | 事件数组 | 循环 `SearchLunarEclipse/SearchSolarEclipse`（峰值 JD 落窗则收录）；元素见 §6.4 |
| `getMeanElements(bodyId)` | {a_au, e, i_deg, period_days} | 读 `planet-facts.js` 静态表（教科书值） |
| `setFrame(jd)` / `getBody(bodyId)` | — | 帧缓存：Map<bodyId, {x,y,z}>，每帧首个调用时计算，后续读缓存 |

精度约定：所有数值保持 double；任何地方不得先转 float 再计算。数值容差见 §10。

### 5.4 相机管理（sim/camera.js）

- 自由视角：`OrbitControls`（`three/addons/controls/OrbitControls.js`），`enableDamping`，旋转/平移/缩放（滚轮 + 触屏捏合）。
- 相机位置与 `camera.userData` 中保存**黄道系双精度坐标**（用于 §3.4 相对原点计算）。
- API：
  - `flyTo(targetPos, dist, duration)`：三次缓动插值目标点与距离，期间禁用用户输入，可中断；
  - `follow(bodyId)`：锁定观察——每帧 `controls.target = 天体黄道位置`；
  - `preset(id)`：机位预设表（`黄道俯视` 相机在 +Y 20 AU 俯视；`地月特写` 距离地球 0.03 AU；`日月地连线` 在黄道面拉远对齐三点；`默认全景` 斜 30° 距离 25 AU）——预设参数在 `config.js` 集中；
  - `reset()`：回到默认全景 + 清空锁定；
  - `setDistanceClamp(min, max)`：随当前关注目标自适应（缩放滑块 U5 与防穿模）。
- 缩放滑块与滚轮都改写 `controls` 的目标距离（同一状态源，互不打架）。

### 5.5 画质档（sim/quality.js）

| 参数 | 高 | 中 | 低 |
|---|---|---|---|
| pixelRatio 上限 | 2 | 1.5 | 1 |
| antialias | on | on | off |
| 球体分段 | 128 | 64 | 32 |
| 贴图分辨率 | 地球/月球 4K，余 2K | 全 2K | 全 1K |
| 星场粒子 | 15000 | 10000 | 5000 |
| 云层 / 大气 / 日冕 | 全开 | 云层+日冕 | 仅日冕 |
| 阴影 | 仅潮汐模块示意场景 | 关 | 关 |

- 自动选档：启动后按高档渲染 3 秒采样帧率 → 平均 <45fps 降中档 → <35fps 降低档；结果 toast 提示「已自动选择 X 画质」，可手动改。
- 运行时 watchdog：每 10 秒滑窗采样，<30fps 持续 2 窗 → 提示降档（toast + 一键确认）。
- 贴图分辨率选择：`TextureLoader` 加载前按档拼文件名（`earth_diffuse_2k.jpg`），失败则沿 4K→2K→1K→程序化 链降级（§7.4）。

### 5.6 太阳（scene/sun.js）

- 几何：球体（分段按档）+ `ShaderMaterial`（光球）+ 2 层日冕精灵 + 可选光晕。
- 光球片元 shader 伪码：

```glsl
// 输入：uv、time；3 层 simplex 噪声（各自缩放/速度/权重）
float n = snoise(uv * 6.0 + time * 0.02) * 0.55
        + snoise(uv * 14.0 - time * 0.05) * 0.30
        + snoise(uv * 32.0 + time * 0.09) * 0.15;   // n ∈ [-1,1]
vec3 c = mix(colorA, colorB, smoothstep(-0.4, 0.8, n)); // 深橙→亮黄
c = mix(c, vec3(1.0, 0.98, 0.92), smoothstep(0.5, 1.0, n)); // 亮斑近白
float limb = pow(1.0 - dot(viewDir, normal), 2.2);   // 边缘略暗
gl_FragColor = vec4(c * (1.0 - 0.25 * limb), 1.0);
```

- 日冕：两个 `THREE.Sprite`（加法混合），canvas 程序化径向渐变纹理（中心亮白→橙→透明），尺寸约 8× 与 16× 太阳视觉半径；随相机距离轻微调整透明度（近景不刺眼）。
- 光照：场景唯一 `PointLight` 置于太阳中心（`decay: 0`，强度调至行星可见；或使用 `DirectionalLight` 每帧指向各行星——**推荐后者**：全景用一盏 DirectionalLight，方向每帧更新为太阳→相机附近主天体，避免 PointLight 距离衰减失控）。月相实验室另设专属灯（§6.2）。

### 5.7 行星工厂（scene/planet.js）

`createPlanet(cfg)`，cfg 来自 `planet-facts.js`：

- 球体 + `MeshStandardMaterial`：`map`（必须）、`normalMap`（月球/火星/水星可选）、`roughnessMap`（地球海洋低粗糙度；可由高光图取反）。
- 轴向：`group.rotation.z = -obliquity`（倾角绕黄道法向的展示近似）；自转见 §3.5。
- 地球附加：云层球（半径 ×1.012，`map=clouds`，transparent，独立转速 ×1.1）；大气辉光（§5.9）。
- 月球：灰调 map + normalMap（环形山凹凸），同步自转。
- 木星/土星：map 直接呈现云带与大红斑/环缝外大气带；土星挂环（§5.8）。
- 金星：厚云 map + 轻微淡黄大气色；火星：map + 极冠（map 自带）。
- 纹理缺失降级链见 §7.4；**任何情况下不得出现无贴图纯色球**。

### 5.8 土星环（scene/rings.js）

- `THREE.RingGeometry(inner=1.24R, outer=2.27R, 128, 1)`，绕 X 轴转 90° 挂到土星（与倾角一致）。
- 顶点 shader 把平面极坐标重映射为 UV（RingGeometry 默认 UV 是平面坐标，必须重算）：

```glsl
varying vec2 vUv;
// position 为平面坐标，重算径向/角向 UV
vUv = vec2((length(position.xz) - inner) / (outer - inner), 0.5);
// 或按角度分段着色（可选精细版）：angle = atan(position.z, position.x)
```

- 片元：`color = texture(ringMap, vUv).rgb * alpha`；`alpha = texture(ringMap, vUv).a`（卡西尼缝由贴图 alpha 体现）；光照 = `dot(lightDir, normal)` 的朗伯项 ×0.7（环面近似双面受光：`side: DoubleSide`，暗面乘 0.3）。开启 `transparent: true, depthWrite: false`（环后星空可见，避免与球体深度冲突；渲染顺序球体→环）。
- 环贴图：1 张径向条带图（1024×8 或 2048×16），由素材裁剪生成；缺失时程序化生成条带噪声环（含卡西尼缝暗带）。

### 5.9 大气辉光（scene/atmosphere.js）

- 球体外壳（半径 ×1.03，`BackSide`），`ShaderMaterial`（加法混合，`depthWrite: false`）：
- 片元伪码：

```glsl
float fresnel = pow(1.0 - abs(dot(viewDir, normal)), 3.0);
vec3 glow = atmosphereColor * fresnel * intensity;
gl_FragColor = vec4(glow, fresnel * opacity);
```

- 应用于地球（淡蓝）、金星（淡黄）、土星/木星/天王星/海王星（各淡色）、火星（极淡红）；可开关（画质档）。

### 5.10 星场（scene/starfield.js）

- 确定性种子 PRNG（mulberry32，seed=20260901 固定）：等面积球面随机方向 + 银河带权重（纬度按高斯集中在倾斜 60° 的银河面 ±15°，权重 3.5），保证银河带肉眼可辨。
- 星等分布：`mag = -1.5 + 6.5 * pow(rand, 0.65)`；亮度 `L = 10^(-0.4 mag)` 映射；色温采样：B-V 从 -0.3（蓝）到 1.8（橙），映射为 `THREE.Color`（预计算 LUT 256 级）。
- 渲染：`THREE.Points` + `ShaderMaterial`（加法混合，`sizeAttenuation`），点精灵用 canvas 生成的径向渐变圆点（唯一允许的程序生成纹理），尺寸随档位。
- 银河带方向与亮度是**观感验收点**：参考夜空银河照片自查截图。

### 5.11 轨道线（scene/orbits.js）

- 每条行星轨道：对该行星公转周期内均匀采样 360 个 JD，`helioEclipticScene` 逐点计算，`THREE.BufferGeometry` + `LineLoop`（颜色 = 行星 UI 色，透明度 0.55，宽度 1px）。这样轨道线与实时位置**严格一致**（含倾角与进动），无静态椭圆误差。
- 生成时机：P1 启动时一次性构建（仅取决于 JD 序列，与运行时间无关）；「完全真实比例」/轨道线开关复用同一几何。
- 月球（示意模式）：以地球为中心半径 0.04 AU 的 `LineLoop` 圆（黄道面内），标注「示意」。

### 5.12 天体标签（scene/labels.js）

- 使用 `CSS2DRenderer`（`three/addons/renderers/CSS2DRenderer.js`）——自动投影、文字锐利；标签：中文名（主）+ 英文（副，可关）；样式：16px/19px、半透明黑底、白字、圆角。
- 跟随各自天体每帧更新；`H` 键（演示净化模式）与标签开关（`L`）联动隐藏。
- 双视口模块（月相实验室）不用 CSS2D，改在视口旁 HTML 固定标注（避免 CSS2D 全局投影错位）。

### 5.13 程序化回退贴图（scene/procedural-textures.js）

- `getFallbackTexture(bodyId)` → `THREE.CanvasTexture`（512×256 或 512×512），确定性噪声：
  - 气态巨行星：横向条带（多层正弦 + 噪声扰动，木星=棕橙白、土星=淡金、天王星=青、海王星=蓝）+ 木星加"大红斑"椭圆斑；
  - 岩态行星：基础色 + 分形噪声明暗 + 随机环形山点（暗圈亮心）；火星偏红、水星灰褐、金星淡黄；
  - 地球：蓝底 + 噪声大陆绿斑 + 白极冠；
  - 月球：灰 + 大量环形山点 + 暗色月海斑块；
  - 太阳：色带 + 亮斑（§5.6 光球纹理缺失时用）。
- 生成结果缓存；真实贴图加载成功后自动替换（`material.map = real; material.needsUpdate = true`）。

## 6. 模块规格

模块基类 `module-base.js`：

```js
class ModuleBase {
  enter(ctx) {}   // ctx: { scene, camera, renderer, root, bus, clock, astro }
  exit() {}       // 注销 bus 订阅、dispose 本模块子图与专属几何/材质/纹理、恢复相机状态
  update(dt) {}
  render() {}     // 单视口渲染；双视口模块重写
}
```

切换流程（main.js）：`oldModule.exit()` → `newModule.enter(ctx)` → `activeModule = newModule`。dispose 清单：`geometry.dispose()`、`material.dispose()`、`texture.dispose()`（共享贴图由缓存层持有，不重复 dispose——贴图缓存集中管理于 `texture-store`，模块只引用）。

### 6.1 全景主模块（orbit-view）

- 场景组成：root（太阳/行星/月球/轨道线/星场/标签）+ 顶底左右 UI。
- 交互：单击天体 → `body.select`（信息面板）；双击或快捷菜单 → `body.focus`（flyTo + follow，再次点击空处解除）；行星菜单 1-8/0/M。
- 比例切换（右上角工具组）：「月地显示」三态、「完全真实比例」开关——切换仅改尺寸因子常量并 toast 说明。
- 轨道线开关、标签开关、「回到今天」快捷入口。
- 性能注意：本模块常驻，切换模块时不 dispose 共享天体网格（置 visible=false 或直接复用）。

### 6.2 月相实验室（moon-phases）

#### 6.2.1 布局与双视口

- 画布左右分屏（各 50%，可拖动分隔条）。**同一 renderer**，双视口渲染：

```js
renderer.setScissorTest(true);
renderer.setViewport(0, 0, w/2, h);   renderer.setScissor(0, 0, w/2, h);
renderer.render(sceneTop, camTop);    // 左：俯视地月系统
renderer.setViewport(w/2, 0, w/2, h); renderer.setScissor(w/2, 0, w/2, h);
renderer.render(sceneEarthView, camEarthView); // 右：从地球看月球
renderer.setScissorTest(false);
```

- 两个独立 `THREE.Scene`（内容不同，共享贴图缓存；仍为单渲染器——R1 不违）。
- 左视口（俯视）：太阳（示意，位于画面一角或按真实几何摆放）、地球（蓝点）、月球（灰球，球上明暗即晨昏线）、地月距离**放大 ×150 示意**（轨道半径 0.04 AU → 视觉清晰）、黄道面参考环。
- 右视口（地球视角）：相机置于地球位置（真实几何），看向月球；月球满屏可见（FOV 60°），背景黑 + 星场。
- 两视口共享全局模拟时钟（`clock.jd`），改动时间条两视图同步。
- 本模块专属光照：`DirectionalLight` 方向每帧 = 太阳→月球单位向量（保证右视口月球明暗真实）。

#### 6.2.2 相位计算与标注

- `getPhase(jd)`：`fraction = Astronomy.Illumination(Body.Moon, t).phase_fraction`；`angle = Astronomy.MoonPhase(t)`（0..360，朔=0/360，望=180）。
- 八相位名映射：朔（fraction≈0）、娥眉月（0<f<0.5 且 angle<180）、上弦（≈0.5，angle≈90）、盈凸月（0.5<f<1，angle<180）、望（≈1）、亏凸月（0.5<f<1，angle>180）、下弦（≈0.5，angle≈270）、残月（0<f<0.5，angle>180）。容差：±3%。
- 顶部大字显示当前相位名 + 照亮百分比（1 位小数）；右视口角标「从地球看月球」、左视口角标「俯视：太阳光从左侧来」。

#### 6.2.3 四个教学机关

1. **光线可视化**（默认开）：从太阳向地月区域发射 24 条平行光线 `LineSegments`（黄线，半透明），方向 = 太阳→月球；月球表面晨昏线由专属 DirectionalLight 自然呈现；再画 3 条"观察视线"（地球→月球，白虚线）。学生旋转左视口相机即可看到角度关系。
2. **地球影子开关**（默认关）：地球处向反日方向画半透明圆锥（长 0.05 AU、底半径 0.004 AU，灰色 alpha 0.25，标「地球影锥（示意）」）。开启瞬间学生可见影子不碰月球——破除误解；月食日期时影子恰罩住月球（联动演示）。
3. **猜一猜**：随机取八相位之一的目标日期（随机相位 ±5 天内）→ 隐藏左视口与所有标注，只留右视口 → 四选项（朔/上弦/望/下弦，随机打乱）→ 答对/答错反馈 → 「揭晓」：镜头动画飞回左视口全景俯视，标注实际相位与几何关系。答错时提示「想想太阳光从哪边来」。
4. **一个月快放**：按钮触发 20 秒线性推进 `clock.jd += 29.53/20 * dt`（期间禁用时间条），结束后停在原相位；再次点击中断。
- 预设按钮：朔/上弦/望/下弦四相位直接跳转（跳转到最近一次该相位的真实日期，用 `SearchMoonPhase` 或二分查找 `angle` 目标值）。

#### 6.2.4 返回

左上角「返回太阳系全景」按钮 → `module.switch('orbit-view')`。

### 6.3 潮汐模块（tides）

- 独立示意图场景（标注「示意图，真实高差仅米级」角标）：
  - 地球：球体（复用地球贴图或简化海洋贴图）+ **水壳**（半径 ×1.02 透明蓝）。
  - 月球：灰球，绕地球半径 0.04 AU 的示意圆轨道（与主视图一致的示意比例），角速度与时钟联动（慢速档）。
  - 太阳：远处亮球 + 平行光示意方向（可开关）。
- 水壳顶点 shader（隆起核心算法）：

```glsl
// uniform: uMoonDir, uSunDir（黄道系单位向量）, uExagger（≈0.018 AU）, uWeights(vec2(2.2, 1.0))
float bulge(vec3 dir, vec3 bodyDir) {
  float cosG = dot(normalize(dir), bodyDir);      // dir=顶点径向
  return 0.5 * (3.0 * cosG * cosG - 1.0);         // P2 勒让德：向月+背月双侧隆起
}
float h = uExagger * (uWeights.x * bulge(vNormal, uMoonDir) + uWeights.y * bulge(vNormal, uSunDir));
vec3 displaced = position + normal * h;
```

  - 顶点法向需近似重算或接受示意误差（示意模块，接受）。
- 观测点演示：地球表面固定纬度标记点随地球**自转**（本模块地球自转角速度与真实比例一致的慢速档，默认 1 小时/秒；档位锁定在慢速区，禁用 >1 天/秒）；右侧 canvas 2D 折线图实时绘制该点水位曲线（CPU 计算，公式 = 常数 + `A_lunar·P2(cosγ_lunar(t)) + A_solar·P2(cosγ_solar(t))`，γ 由自转相位与月/日方向求得）——一周期显示两次波峰，配合文字「约 24 小时 50 分两涨两落」。
- 大潮/小潮预设按钮：把月球摆到朔望几何（日-地-月共线，月球在日侧或对侧）或上下弦几何（日月方向垂直），toast 解释「朔望大潮、上下弦小潮」。
- 返回按钮同 6.2.4。

### 6.4 日月食模块（eclipse）

- 事件列表（右栏）：默认搜索 2025-01-01 ~ 2028-12-31，条目 = {类型图标, 名称（如「2026-08-12 日全食」）, 峰值时间（本地）, 可见性摘要（日食：经纬度；月食：食分）}；「刷新范围」按钮。
- 数据源：`SearchSolarEclipse(t)` / `SearchLunarEclipse(t)` 循环推进（每次 `peak` 后 +10 天继续搜），`kind` 映射中文（annular→日环食/total→日全食或月全食/partial→偏食/penumbral→半影月食——**半影月食默认隐藏**，复选框可选显示，避免混淆）。
- 点击事件：`clock.jump(peakJd)`；日月地按 §3.2 真实几何摆放；相机预设「日月地连线」。
- 影锥（示意，标注）：日食 = 自月球向反日方向圆锥（本影深灰 alpha 0.3、半影浅灰 alpha 0.15，半影半角 ≈0.27°、本影 ≈0.24°，长度延至地月距 ×1.1，**宽度放大 ×40 便于看见**）；月食 = 自地球向反日方向双锥（地影更长，真实几何 + 宽度放大）。开关可切换。
- 时间线：±3 天拖动 scrub（重排几何），影锥随动，展示「影锥扫过地球/月球」的过程。
- 科普卡：日食 = 朔 + 月球近黄道交点；月食 = 望 + 月球近黄道交点。标注「月球轨道倾角 5.1°，因此并非每个朔望都发生食」。

### 7.4 加载与降级链

`texture-store.js`（实现于 scene/ 下）：`get(body, type)` → 按画质档取 res 拼文件名 → `TextureLoader.load` → 失败降级 4K→2K→1K → 仍失败 `getFallbackTexture(body)` → toast「部分贴图加载失败，已使用简化外观」（U2）。所有成功加载的贴图缓存 Map，供模块切换复用（不得重复加载）。

## 9. 性能预算与验收方法

| 指标 | 高 | 中 | 低 |
|---|---|---|---|
| draw calls（全景） | ≤120 | ≤90 | ≤60 |
| 三角形总量（全景） | ≤80 万 | ≤30 万 | ≤10 万 |
| 纹理显存估算 | ≤1.2 GB | ≤600 MB | ≤300 MB |
| 目标帧率（1080p 独显 1050 级） | p95 ≤16.7ms | — | — |
| 目标帧率（集显老机器，低档） | — | — | p95 ≤33ms |
| 4K（上限目标，独显高端） | p95 ≤25ms | — | — |

- 验收方法：内置轻量 FPS 面板（F3 开关，显示当前帧时间 + p95 滑窗）；基准机位三连测（默认全景 30s、地球特写 30s、月相双视口 30s）采样记录。
- 内存验收（U13）：连续轮换四模块 + 反复缩放 45 分钟，内存曲线平稳（`performance.memory` 采样），帧率不劣化；模块切换后纹理缓存命中、无新增纹理加载。
- 启动验收（U1）：双击离线版 index.html → 秒表到出现运转画面 ≤5s。

## 10. 科学回归测试规格（tests/，node --test）

> 定位：**教学正确性的保险丝**。任何开发阶段跑 `npm test` 必须全绿。以下参考值允许容差；执行模型先按容差跑通并记录实测值，再与 NASA 官方目录核对后把黄金值固化为测试常量（写注释注明来源）。

| 用例 | 断言 | 容差 |
|---|---|---|
| J2000 地球日心黄经 | `helioEclipticScene(Earth, 2451545.0)` → 黄经 ≈ 100.46°、黄纬 ≈ 0° | ±1°（坐标系/框架差异容差） |
| J2000 地日距离 | 0.9833 AU | ±0.01 |
| JD↔Date 往返 | `dateToJd(jdToDate(jd)) == jd`（含 1900/2100 边界） | ±1e-9 天 |
| 时钟钳制 | 越界 jump 被钳制并返回提示标志 | 精确 |
| 2026-02-17 日环食 | `searchEclipses` 含 kind='annular'，峰值日期 2026-02-17 | 日期 ±0.1d，时刻与 NASA 目录 ±10min |
| 2026-08-12 日全食 | kind='total'，2026-08-12 | 同上 |
| 2026-03-03 月全食 | kind='total'（lunar），2026-03-03 | 同上 |
| 2026-08-28 月偏食 | kind='partial'（lunar），2026-08-28 | 同上 |
| 月相-望 | 2026-03-03 附近 `getPhase().fraction ≥ 0.995` | — |
| 月相-朔 | 2026-08-12 附近 `fraction ≤ 0.005` | — |
| 月球同步自转 | 月球朝向地球面恒定（几何恒等式） | 精确 |
| 金星逆行 | 自转角速度为负 | 精确 |

核对来源：NASA GSFC Eclipse 目录（eclipse.gsfc.nasa.gov）、USNO / Meeus《Astronomical Algorithms》示例、NASA/JPL 行星概况表。
