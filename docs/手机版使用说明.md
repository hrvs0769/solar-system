# 手机版使用说明

## 是什么
一个**在手机浏览器可直接运行**的版本（`mobile.html`），复用与桌面版完全相同的天文计算与教学模块（VSOP87 位置、月相、潮汐、日月食），但整套 UI 为**触屏 + 竖屏**重新设计。

## 如何用手机打开
手机版**通过网址访问**（手机普遍联网/在同一局域网，不依赖双击文件）：

```bash
# 构建后在 dist 目录起一个静态服务器（局域网/公网均可）
cd dist && python3 -m http.server 8000
```
- 同局域网手机（或电脑）打开：`http://<电脑IP>:8000/mobile.html`（电脑IP 用 `ipconfig` 查看，或用公网服务器）。
- 也可把整个 `dist/` 部署到任意静态托管（局域网 or 云），公网域名后手机直接访问 `/mobile.html`。
- 桌面版仍为 `index.html`（离线双击版在 `dist-offline/`）。

## 手机交互（重设计）
| 操作 | 效果 |
|---|---|
| 底部 4 个 Tab | 全景 / 月相 / 潮汐 / 日月食 切换 |
| 单指拖动 | 旋转视角 |
| 双指捏合 | 缩放（+ 平移） |
| 点横滑行星条 | 跳转并弹出对应星球资料 |
| 右上「?」 | 操作说明 |
| 时间条（⏸ / 今 / 日期 / 1秒=..） | 播放暂停、回到今天、查看日期、调速 |
| 底部抽屉 | 点行星后滑出资料，点「✕」收起 |
| 「⛶」 | 全屏 |

- 月相实验室在**竖屏**为**上下分屏**（上=俯视被照亮半球，下=从地球看月球），横屏自动切为左右分屏。

## 与桌面版差异
- 桌面离线版（`dist-offline/index.html`）可**双击离线运行**（课堂大屏）；手机版因文件:// 限制改为**网址访问**。
- 核心（天体位置、月相、教学模块、真实贴图）两者完全一致，仅交互层不同。

## 验证
`npm run test:mobile`：手机视口（390×844）加载 mobile.html，检测启动、4 Tab、模块切换、月相预设，无脚本报错。
