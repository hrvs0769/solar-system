## 1. 项目概述

### 1.1 背景

需求方为中学物理教师，需要在**课堂大屏**上向学生展示一个**三维立体的太阳系运转系统**：学生通过浏览器直接打开，就能看到太阳与行星的真实外观和实时运转，理解天体运动的基本规律（月球绕地球、月相成因、潮汐成因等）。

### 1.2 目标

构建一个**科学正确、外观逼真、中文界面、离线可用**的 3D 太阳系教学应用，在教室电脑（独立显卡/较新机型）上以大屏方式流畅运行，供课堂讲解演示。

### 1.3 使用场景

- 教师打开应用 → 全屏投放到课堂大屏
- 展示太阳系全景公转，或切换专项教学模块（月相 / 潮汐 / 日月食）
- 讲解时可暂停、变速、跳转日期、点击行星查看科普数据
- 教师课前 30 秒完成准备；课上零培训操作（详见第 12 节 U1–U16）

## 2. 需求梳理

### 2.1 明确需求（原始诉求拆解）

| 编号 | 需求 | 说明 |
|---|---|---|
| R1 | 浏览器运行 + 大屏展示 | 打开即用，全屏演示，鼠标 + 触屏均可 |
| R2 | 3D 立体太阳系 | 可自由旋转、缩放、平移的摄像机视角（360° 无死角观察） |
| R3 | 逼真星球外观 | 太阳与行星非光秃球体：真实卫星影像贴图、大气层、云层、土星环、日冕 |
| R4 | 天体运转教学展示 | 月亮绕地球、月相阴晴圆缺、潮汐成因 |
| R5 | 科学正确性 | 采用真实天文数据与理论，不教错学生 |

### 2.2 隐藏需求（原始描述未提及、但设计必须考虑）

| 编号 | 隐藏需求 | 处理方案 |
|---|---|---|
| H1 | **显示比例矛盾** | 太阳直径≈地球 109 倍，地日距离≈地球直径 1.18 万倍，真实比例下行星不可见。默认「距离真实 + 尺寸放大至可见」，另提供「完全真实比例」对比模式 |
| H2 | **时间尺度矛盾** | 水星公转 88 天、海王星 165 年，课堂 45 分钟看不完。必须有时间加速/暂停/单步/日期跳转 |
| H3 | **月相成因需双视角** | 仅俯视看不出月相成因；需「俯视图（被照亮半球）+ 从地球看月球」两视角同步（v2.1 升级为「月相实验室」，见 4.2） |
| H4 | **离线能力** | 课堂电脑可能无外网：交付离线打包版，纹理本地化，不依赖 CDN |
| H5 | **性能与硬件差异** | 三档画质（高/中/低）+ 启动自动选档，独显默认高档，老机器保底可跑 |
| H6 | **科学术语教学易错点** | 月相≠地球影子（那是月食）；潮汐主因是月球（次为太阳）引潮力的**引力差**，自转决定周期——讲解文案需严谨 |
| H7 | **内容版权与署名** | 素材采用 Solar System Scope（CC BY 4.0，需署名）+ NASA 公有领域（PD），「关于」页内置署名与数据来源 |
| H8 | **内容审校** | 所有面向学生的中文科普文案，交付时标记「待老师审校」，未审校不得进课堂 |
| H9 | **主视图月地距离矛盾** | 距离真实时月球距地球 38 万 km，同样不可见。默认「月地放大示意」（标注），另提供「真实比例 / 隐藏月球」切换 |
| H10 | **老机器 WebGL2 支持** | Three.js 现行版本仅支持 WebGL2；启动检测 + 中文提示，最低 Chrome / Edge 100+ |
| H11 | **大屏触控与缩放操作** | 触屏无滚轮，需界面缩放滑块；另需一键复位视角防"转晕" |

## 3. 技术方案

### 3.1 总体架构

```
┌─────────────────────────── 浏览器 ───────────────────────────┐
│  UI 层  顶部导航（模式切换）/ 时间控制条 / 缩放滑块 / 行星快捷跳转 / 数据面板 │
│  模块层  太阳系全景 · 月相实验室 · 潮汐成因 · 日食月食 · 行星数据面板      │
│  场景层  Three.js：太阳/行星/云层/土星环/大气辉光/轨道线/星场（单 WebGL 上下文）│
│  计算层  astronomy-engine：行星=VSOP87，月球=内置月表；月相、日月食搜索      │
│  时钟层  模拟历书时钟（JD ↔ Date 换算，暂停/变速/单步/跳转，UTC 基准）      │
└───────────────────────────────────────────────────────────────┘
```

### 3.2 技术选型与理由

| 组件 | 选择 | 理由 |
|---|---|---|
| 3D 渲染 | **Three.js**（最新稳定版，锁定版本，需 WebGL2） | WebGL 生态最成熟、文档最全、体积合理；无需 Babylon（重）或 Cesium（地理级，过重）。注：现行版本已移除 WebGL1，故 H10 要求启动检测 |
| 科学计算 | **astronomy-engine**（MIT 协议，纯 JS、零依赖、离线） | 行星位置用 VSOP87 行星理论（NASA/JPL 数据谱系，内行星精度角秒级）；月球位置由其**内置月表**（独立周期项模型，弧分级，教学绰绰有余）解算；免费提供月球照亮比例、日月食事件搜索——三大教学模块的核心数据 |
| 构建工具 | **Vite** + `vite-plugin-singlefile` | 开发热更新；构建期同时产出①离线打包版（JS/CSS 全内联 + `textures/` 外部文件夹）②常规多文件在线版 |
| 星场 | 程序化粒子（约 1.5 万星 + 银河带密度） | 不依赖外部大图，体积小、离线友好 |

### 3.4 渲染精度策略（v2.1 新增，本项目第一技术风险）

- CPU 端全部 **double** 计算（单位 AU / JD），计算精度无虞；
- GPU 端 float32 在 AU 尺度下分辨率约 18 km——直接渲染会行星抖动、近景 z-fighting；
- 对策三件套：①每帧**相机相对原点**（场景整体平移，坐标始终小量级）；②**对数深度缓冲**（同时容纳 30 AU 轨道与米级近景）；③近/远裁剪面随相机动态自适应；
- 具体实现细节见《详细设计文档》第 3 章。

## 4. 教学功能设计（科学性为本）

### 4.1 太阳系全景（主模块）

- 八大行星 + 太阳 + 月球（绕地球）：**行星**位置由 VSOP87 实时解算，**月球**由 astronomy-engine 内置月表解算地心位置后再与地球日心位置合成；真实椭圆轨道、轨道倾角、近日点快/远日点慢（自动满足开普勒定律）。
- 轨道线由**实际解算轨迹采样**绘制（与行星位置严格一致，非静态椭圆）。
- 月球显示三态：默认「月地放大示意」（标注"示意"）/「真实比例」（不可见，教学点）/「隐藏」。
- 数据面板展示行星开普勒根数（a / e / i / 公转周期，采用 NASA/JPL **平均根数**——教科书值）与物理参数。
- 比例策略：默认「距离真实 + 尺寸放大至可见」（行星视觉半径 = 真实 ×300，太阳 ×10 + 日冕）；「完全真实比例」一键对比模式——此时地球确实只是一个点，本身就是教学点。
- 交互：点击行星 → 选中 + 数据面板；**锁定观察**（镜头飞近并跟随）；**一键复位视角**（回到全景默认机位）。

### 4.2 月相实验室（v2.1 由"月相成因"模块升级）

**教学要点：月相不是地球的影子造成的（那是月食），而是月球绕地球公转使「太阳照亮半球的相对角度」不断变化所致。**

- 双视角分屏：左 = 月球轨道俯视（展示被照亮半球朝向），右 = 从地球望向月球的实时渲染；两视图共享同一模拟时钟，实时联动；含月相名称标注（朔 / 上弦 / 望 / 下弦等八相位）与「照亮百分比」（引擎精确计算）。
- **光线可视化开关（顿悟核心机关）**：画出太阳→月球真实方向光线与晨昏线，学生拖动视角即可亲眼看到"地球视角的月牙形状 = 俯视视角被照亮半球的方向"，打通两视角的几何联系。
- **「地球的影子在哪」开关**：画出示意的地球影锥，可见影子平时并不扫到月球（只有月食时才扫到），直接破除"月相=地球影子"的头号误解。
- **"猜一猜"互动模式**：随机跳转日期 → 先给地球视角 → 学生猜日月地几何关系 → 镜头自动飞到俯视视角揭晓验证。
- **"一个月快放"按钮**：约 20 秒播完一个朔望月（29.53 天），看月相连续变化一圈。
- 附对比讲解：月食发生在「望」，日食发生在「朔」，区分月相与掩食。

### 4.3 潮汐成因（夸张示意）

**教学要点：潮汐主因是月球（次为太阳）引力跨越地球直径产生的「引力差」（引潮力）；地球自转决定某地约每 24 小时 50 分（一个太阴日）经历两次涨潮、两次落潮。**

- 沿地月连线展示双侧潮汐隆起（夸张显示，界面明确标注「示意图，真实高差仅米级」）。
- 叠加太阳引潮力 → 朔望大潮、上下弦小潮（日月引潮力之比约 2.2 : 1）。
- 地球表面放置「观测点」随自转扫过隆起，直观呈现一天两涨两落，并附观测点水位-时间曲线。
- 本模块使用**独立慢速时间档**（默认 1 小时/秒），避免高速倍率下地球自转过快导致演示无法看清。

### 4.4 日食 / 月食

- 用引擎搜索**真实事件**（如 2026-02-17 日环食、2026-08-12 日全食、2026-03-03 月全食、2026-08-28 月偏食等），生成「近期事件列表」。
- 点击事件即把日月地调至当时几何关系；透明本影/半影锥显示遮挡范围——**影锥为夸张示意**（真实尺度下月影锥极细不可见），界面标注「示意图」。
- 时间线动画（事件前后 ±3 天拖动），展示影锥扫过过程。
- 讲解「朔 + 黄道交点附近 = 日食；望 + 交点附近 = 月食」。

### 4.5 行星数据面板

- 点击任意星体：中文科普资料（距离 / 公转周期 / 自转周期 / 直径 / 温度 / 卫星数 / 轴倾角 / 简介），数据取自 NASA/JPL 行星概况表。
- 轨道根数为**平均根数（教科书值）**，界面注明口径，与课本一致。
- ⚠️ 所有中文文案为 AI 起草，交付时**必须经老师审校**后才可用于课堂；文案独立存放于 `data/planet-facts.js`，老师可自行改字，无需开发介入。

## 5. 视觉与交互设计

### 5.1 视觉效果与素材规格（v2.1 新增素材来源列）

| 对象 | 效果 | 纹理来源（许可） |
|---|---|---|
| 太阳 | SDO 风格贴图 + 程序化光球层噪声（动态）+ 日冕辉光（加法混合精灵），非单一发光球 | NASA SDO 实拍日面（PD）+ 程序化 |
| 地球 | Blue Marble 型贴图 + 独立旋转云层 + 海洋镜面反射 + 大气边缘辉光（菲涅尔） | NASA Blue Marble / Visible Earth（PD），2K 默认、4K 可选 |
| 土星 | 程序化环带 shader（含卡西尼缝），锐利清晰 | 卡西尼号实拍环面（NASA PD） |
| 木星 | 云带贴图 + 大红斑 | 卡西尼 / 朱诺号实拍（NASA PD） |
| 月球 | 火山灰纹理 + 环形山细节（法线贴图） | NASA LROC / USGS 实拍月面（PD） |
| 火星/水星/金星等 | 对应真实表面纹理 + 氛围色调 | NASA Viking / MESSENGER / 麦哲伦实拍（PD） |
| 天王星/海王星 | 贴图 + 氛围色调（NASA 原图分辨率低） | SSS 艺术补绘（CC BY 4.0，署名） |
| 背景 | 程序化星场（色彩梯度 + 银河带） | 纯程序生成（无素材） |

- 材质规格：每颗星 = 颜色贴图 +（法线/粗糙度贴图按需），绝不使用纯色球；贴图总预算 ≤300MB；默认 2K。
- 兜底：任何贴图缺失/加载失败 → **程序化回退贴图**（气态=噪声云带、岩态=噪声+环形山、太阳=色带），应用永不白屏、永不出现光秃纯色球。
- 逐文件来源与署名见 `public/textures/MANIFEST.json` 与「关于」页。
- 明确边界：不做电影级 CG 与后期特效管线（Bloom/SSAO 等），辉光由程序化精灵与 shader 实现；动态细节（云层流动、日面颗粒）为简化动画，静态观感对标卫星照片（详见 4.5 验收）。

### 5.2 课堂交互（v2.1 更新）

- 顶栏：模式切换（全景 / 月相实验室 / 潮汐 / 日月食）
- 底部：时间控制（暂停/播放、倍速「1秒=1分钟…1年」、单步、日期跳转、回到今天）+ **缩放滑块**（全景↔行星特写连续可拖，与滚轮/捏合并行）+ **一键复位视角**
- 左侧：行星快速跳转（快捷键 1-8，太阳 0，月球 M）
- 键盘：空格=暂停、+/-=倍速、H=隐藏界面（演示净化模式）、F1=帮助浮层、Esc=退出全屏/关闭面板
- 大字高对比，适配大屏观感；鼠标 + 触屏（触控目标 ≥48px）；中文界面（行星名中文为主，可选英文小字）
- 全部易用性要求见第 12 节 U1–U16

## 6. 性能与风险

| 风险 | 对策 |
|---|---|
| 渲染精度：行星抖动 / 近景 z-fighting | 相机相对原点 + 对数深度缓冲 + 自适应裁剪面（§3.4）；验收：全景视角下行星静止时无可见抖动 |
| 独立显卡机型高画质、老机器卡顿 | 三档画质（高/中/低）：贴图分辨率、粒子数、抗锯齿、像素比、阴影开关；启动采样帧率自动选档 + **运行时掉帧监测自动降档** |
| 纹理下载失败 | 程序化回退贴图，应用永不白屏；下载成功后固化到仓库 |
| 老浏览器 / 无 WebGL2 | 要求 Chrome / Edge 100+（含 WebGL2 检测与中文提示）；说明文档写明最低要求 |
| file:// 离线兼容 | 离线打包版 JS/CSS 内联，纹理一律 ImageLoader 相对路径加载（不用 fetch/XHR），数据全部内联进 JS；另附一条命令的本地静态服务脚本兜底 |
| 数据正确性 | 关键数值交叉验证固化为 **CI 自动化回归测试**（J2000 行星位置、2026 四次日月食、已知月相日期与权威公布值比对）；科普文案老师审校 |

| 纹理体积失控 | 预算 ≤300MB；默认 2K；逐文件 MANIFEST 记账 |
| 版权风险 | MANIFEST + 「关于」页署名（CC BY 4.0 义务）；NASA PD 注明来源 |

## 9. 能力边界（能实现 / 半实现 / 不能实现）

### ✅ 能实现

- 真实精确的八大行星 + 月球运转与逼真外观（VSOP87 行星位置、内置月表月球位置、NASA/Solar System Scope 纹理、云层/环/大气/日冕）
- 月相、潮汐、日月食三大成因的教学演示（真实事件、真实轨道、科普正确）
- 离线打包运行、中文界面、三档画质、课堂交互（键盘/触屏/大屏/缩放滑块/机位预设）

### ⚠️ 半实现（教学需要，明确标注）

- 潮汐隆起与部分天体比例为**夸张示意**，界面标注「示意图」字样（真实尺度肉眼不可见）
- 主视图月地距离为**放大示意**（可切换真实比例——月球小到不可见，作为对比教学点保留）
- 日月食本影/半影锥为**夸张示意**（真实影锥极细不可见）
- 「完全真实比例」下行星小到不可见——这是宇宙真实，作为对比教学点保留

### ❌ 不做 / 做不到

1. 相对论效应、光行差、光传播延迟
2. N 体引力实时自演化底座（采用 VSOP87 精确位置；如需可另立「两体引力演示」微模块）
3. 电影级 CG 渲染与后期特效管线（Bloom/SSAO 等）——实时 WebGL 的物理上限；辉光由程序化精灵实现
4. 全部小行星 / 彗星 / 柯伊伯带目录（可做小行星带示意粒子带）
5. 真实「今晚夜空」地心星图（Stellarium 类产品，另立项）
6. VR / AR 与多端协作
7. AI 起草的科普文案未经老师审核不承诺准确——**文案审校是上线前置条件**

## 附录 A：关键物理表述（供审校）

- **月相**：月球绕地球公转（朔望周期 29.53 天），太阳照亮半球的相对视角变化形成阴晴圆缺；月相**不是**地球影子造成，影子造成的分别是**日食/月食**。
- **潮汐**：月球（次级为太阳）引力跨越地球直径产生**引力差**（引潮力），形成两侧潮汐隆起；地球**自转**使某地**约每 24 小时 50 分（一个太阴日）**经历两次涨潮、两次落潮。朔望（日月地近似共线）为大潮，上下弦为小潮。
- **日食/月食**：日食 = 朔（新月）+ 月球接近黄道交点；月食 = 望（满月）+ 月球接近黄道交点。
- **开普勒定律**：椭圆轨道、面积定律（近日点快）、谐和定律——由精确轨道数据天然满足；数据面板展示**平均根数（教科书值）**。
