# 课堂使用说明

## 如何打开
- **快捷方式（推荐）**：拷贝 `/dist-offline/` 整个文件夹到教室电脑（含 `index.html` 和 `textures` 文件夹），双击 `index.html` 即可全屏运行——**无需联网、无需安装**。
- 在线版：将 `dist/` 部署到局域网/服务器，浏览器访问。
- 开发：`npm install` 后 `npm run dev`，浏览器打开 http://localhost:5173。

## 最低要求
- Chrome / Edge 100+（需支持 WebGL2）；不支持的浏览器会给出中文提示。

## 快捷键（可打印贴墙）

| 键 | 功能 |
|---|---|
| 空格 | 播放 / 暂停 |
| ＋ / − | 升速 / 降速 |
| 0–8 | 跳转 太阳 / 水星…海王星 |
| M | 跳转月球 |
| L | 显示 / 隐藏标签 |
| H | 演示净化模式（隐藏全部界面） |
| F1 | 打开帮助 |
| R | 复位视角 |
| F11 | 全屏 |
| Esc | 退出全屏 / 关闭面板 |

## 操作
- **鼠标**：左键旋转 · 滚轮缩放 · 右键平移。
- **触屏**：单指旋转 · 双指捏合缩放。
- 点击任意星球：右侧弹出科普数据，镜头自动对准。
- 底部：缩放滑块、单步（±1 天）、倍速（1 秒=1 分钟…1 年）、日期跳转、回到今天（「今」按钮）。

## 教学模块（顶栏切换）
1. **全景**：太阳系全系运转，可在右上角切换「完全真实比例」「月地显示」。
2. **月相实验室**：左=俯视地被照亮半球，右=从地球看月球；含「光线」「地球影子」「猜一猜」「一个月快放」「朔/上弦/望/下弦」。
3. **潮汐**：夸张显示潮汐隆起与水位曲线；「朔望大潮」「上下弦小潮」预设。
4. **日月食**：真实事件列表，点击定位；时间线 ±3 天；影锥为示意。

## 常见问题
- **星球看起来很小/很大**：默认「教学比例」放大了行星尺寸；「完全真实比例」下行星几乎不可见——这是宇宙真实的尺度，本身是教学点。
- **月球太小**：默认「月地放大示意」以保证可见；可切换真实比例/隐藏。
- **不显示简介数据文案进入课堂**：全部科普文案为 AI 起草，需**物理老师审校**（见软件「关于」页与代码 `data/planet-facts.js` 的 `reviewStatus`）。
