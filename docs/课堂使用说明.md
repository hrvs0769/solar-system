# 课堂使用说明

## 如何打开
- **快捷方式（推荐）**：拷贝 `/dist-offline/` 整个文件夹到教室电脑（含 `index.html` 和 `textures` 文件夹），双击 `index.html` 即可全屏运行——**无需联网、无需安装**。
- 在线版：将 `dist/` 部署到局域网/服务器，浏览器访问。
- 开发：`npm install` 后 `npm run dev`，浏览器打开 http://localhost:5173。

## 最低要求
- Chrome / Edge 100+（需支持 WebGL2）；不支持的浏览器会给出中文提示。

## 快捷键（可打印贴墙）

| 键 | 功能 |
|---|---|
| 空格 | 播放 / 暂停 |
| ＋ / − | 升速 / 降速 |
| 0–8 | 跳转 太阳 / 水星…海王星 |
| M | 跳转月球 |
| L | 显示 / 隐藏标签 |
| H | 演示净化模式（隐藏全部界面） |
| F1 | 打开帮助 |
| R | 复位视角 |
| F11 | 全屏 |
| Esc | 退出全屏 / 关闭面板 |

> 儿童模式下大部分快捷键仍可用，但顶栏只保留常用按钮，避免误触。

## 操作
- **鼠标**：左键旋转 · 滚轮缩放 · 右键平移。
- **触屏**：单指旋转 · 双指捏合缩放。
- 点击任意星球：右侧弹出科普数据，镜头自动对准。
- 底部：缩放滑块、单步（±1 天）、倍速（1 秒=1 分钟…1 年）、日期跳转、回到今天（「今」按钮）。

## 儿童模式（给幼儿园 / 小学低年级）
顶栏点 **🌱** 一键开启，再点一次退出（设置会记住，下次打开保持上次的状态）。

开启后会自动：
- **字变大、按钮变大**：字号放大 35%，方便小朋友看和点。
- **收起专业控件**：画质档位、倍速、日期输入、书签、天象表、拍照、二维码、卫星 Tab 等全部隐藏，界面只剩「看」和「玩」。
- **切换儿童版文案**：星球介绍、月相说明、日月食成因、奔月任务解说全部换成更口语、更短的说法，专业术语（黄道面、交点、倾角）不再出现。
- **月相「猜一猜」变成看图选**：四个选项是月相图形，不识字也能答。
- **「光线」「地球影子」开关收起**：减少干扰。

## 语音朗读与背景音乐
- 顶栏 **🔊**：打开后，点界面上的「🔊 读一读 / 朗读」按钮，浏览器会用中文把这段文字念出来（用的是系统自带语音，不需要联网下载音频）。再点 🔊 可关闭。
- 顶栏 **🎵**：播放一段轻柔的背景音乐，音量已调低，不会盖过讲解；再点一次停止。音乐由浏览器实时合成，不占文件体积。

## 教学模块（顶栏切换）
1. **全景**：太阳系全系运转，可在右上角切换「完全真实比例」「月地显示」；右下角 **🚀 嫦娥奔月** 播放完整的发射—入轨—转移—绕月—着陆动画（约 80 秒，中途可点「⏹ 停止任务」）。
2. **月相实验室**：左=俯视地被照亮半球，右=从地球看月球；含「光线」「地球影子」「猜一猜」「一个月快放」「朔/上弦/望/下弦」。
3. **日月食**：左侧为成因示意（月球轨道倾角→只有靠近交点才发生），右侧为真实感模拟；右侧列表是未来真实事件，点击即跳到该次；时间线 ±3 天；影锥为示意。
4. **卫星**：对地观测卫星绕地球公转，「看卫星细节 / 看全貌」切换视角。

## 常见问题
- **星球看起来很小/很大**：默认「教学比例」放大了行星尺寸；「完全真实比例」下行星几乎不可见——这是宇宙真实的尺度，本身是教学点。
- **月球太小**：默认「月地放大示意」以保证可见；可切换真实比例/隐藏。
- **没有声音**：语音朗读依赖系统中文语音包；若浏览器没有中文语音，朗读会静音，不影响其它功能。背景音乐需要先点一下页面（浏览器规定）。
- **投影看不清字**：建议全屏（顶栏 ⛶ 或 F11），或开启儿童模式放大字号。
- **画面突然黑掉/出现「画面中断了」**：电脑休眠唤醒或切换投影时会触发显卡重置，软件会自动重新加载；若没有自动恢复，点提示里的「重新开始」即可。
- **星球是纯色的、没有纹理**：说明 `textures` 文件夹没跟着 `index.html` 一起拷贝。软件会自动用纯色代替，能正常上课，但画面不如有贴图好看——把整个 `dist-offline` 文件夹一起拷过去即可。
