# 璀璨太阳系 · 项目说明书

> 面向浏览器（桌面 + 手机）的**中学天文/物理教学演示系统**。用真实历表驱动太阳系运转，并提供四个可交互的教学模块，其中「嫦娥奔月」是一段完整的地月任务电影动画。
>
> 本文档描述项目**当前**状态。最后更新：随 `main` 分支最新提交。

---

## 1. 一句话定位

| 项目 | 说明 |
| --- | --- |
| 名称 | 璀璨太阳系（solar-system） |
| 类型 | 纯前端 3D 教学演示（无需后端、可离线） |
| 目标用户 | 中学物理/地理教师与学生（课堂大屏 + 学生手机/平板） |
| 运行环境 | 支持 WebGL2 的现代浏览器（Chrome / Edge / Safari） |
| 三个依赖 | `three`（渲染）、`astronomy-engine`（真实历表）、`qrcode`（手机扫码） |
| 许可证与素材 | 见 `docs/素材来源与许可.md`（贴图 CC BY 4.0 / NASA 公有领域） |

## 2. 快速上手

### 2.1 直接用（推荐教师）

| 场景 | 做法 |
| --- | --- |
| 在线访问 | `https://hrvs0769.github.io/solar-system/` （手机版 `/mobile.html`） |

| 学生手机 | 顶栏「📱」按钮生成二维码；可填入局域网地址，手机连同一 WiFi 扫码直达 `mobile.html` |

### 2.2 开发

```bash
npm install
npm run dev            # Vite 开发服务器
npm run build:web      # → dist/（桌面 index.html + 手机 mobile.html，多页）
npm run build:offline  # → dist-offline/（单文件，桌面；public/textures 保持外部目录）
npm run serve          # 局域网静态服务（手机端调试用）
```

### 2.3 一键回归

```bash
npm run test:all       # 构建(离线+在线) + 单元测试 + e2e + 手机端自检
```

## 3. 功能总览

### 3.1 全景（太阳系运行）— `src/modules/orbit-view.js`

- 太阳 + 八大行星 + 月球，位置来自 **astronomy-engine 真实历表**（不是近似公式）。
- 行星：贴图 + 云层（地球）+ 土星环（含卡西尼缝）+ 大气边缘辉光（菲涅尔壳）。
- 太阳：光球噪声 shader 自发光 + 日冕辉光壳。
- 星场：程序化、种子确定、含银河带权重与色温分布。
- 轨道线由**实际解算轨迹采样**得到，与行星位置严格一致。
- 交互：自由旋转/缩放、锁定天体、「⚖️ 比例模式」在**教学比例**与**完全真实比例**间切换、月球三态（示意/真实位置/放大）、标签开关、右侧资料面板。

### 3.2 月相实验室 — `src/modules/moon-phases.js`

双视图：左侧俯视几何成因（太阳平行光、地球→月球视线、日地月夹角弧、轨道上朔/上弦/望/下弦四个打点），右侧真实感光照明暗面，用于讲清「月相是几何关系，不是地球影子」。

### 3.3 日月食 — `src/modules/eclipse.js`

双视图：左=成因示意（月球轨道倾角 → 只有靠近交点才可能发生食），右=真实感模拟（日/地/月 + 影锥），并可自动跳到**下一次真实日月食**。

### 3.4 卫星 — `src/modules/satellite.js`

一颗细节较完整的对地观测卫星绕地球公转，支持捏合缩放与旋转，可拉远看整体、拉近看细节。

### 3.5 嫦娥奔月（电影模块）— `src/modules/lunar-mission.js`（约 1475 行）

一段约 **78 秒**的完整任务电影，**12 个阶段**：

| # | 阶段 | 时长 | 内容 |
| --- | --- | --- | --- |
| 1 | `COUNTDOWN` 发射倒计时 | 4.0s | 文昌发射场，脐带塔/厂房/储罐/海与林带 |
| 2 | `IGNITION` 点火 | 2.0s | 尾焰 + 导流槽水雾，烟云贴地铺开 |
| 3 | `LIFTOFF` 升空 | 6.5s | 垂直上升，相机边升边退保留发射场 |
| 4 | `SPHERE` 俯瞰地球 | 9.0s | 地面淡出，地球弧线展开（「原来是个球」） |
| 5 | `STAGE_SEP` 分级脱离 | 4.0s | 4 台助推器**各自**外飘翻滚 + 分离白烟 |
| 6 | `EARTH_ORBIT` 地球轨道 | 15.0s | 一级分离 → 抛整流罩 → 入轨加速 |
| 7 | `DEPLOY` 上面级分离·嫦娥展开 | 5.5s | **「变身」镜头**：太阳翼转出伸出、天线抬起，上面级退场 |
| 8 | `TRANSFER` 地月转移 | 10.0s | 沿椭圆奔月（开普勒「近快远慢」+ 速度箭头） |
| 9 | `LOI` 月球制动 | 3.0s | 减速被月球捕获 |
| 10 | `LUNAR_ORBIT` 绕月飞行 | 11.0s | 绕月一圈（可拖动旋转） |
| 11 | `LANDING` 登月下降 | 8.5s | 着陆器径向垂直下降 |
| 12 | `LANDED` 着陆月球 | — | 成功弹窗 → 可留在月面自由观察 → 再退出 |

电影化的具体做法：

- **独立场景**：自带 `THREE.Scene` 与一套「电影比例尺」（非天文单位），主循环在任务期间渲染它，复用全局相机/渲染器/HUD/弹窗。
- **真实光影**：平行光太阳 + 2048 软阴影（PCFSoft）、ACES 色调映射、程序化 IBL 环境贴图、大气雾与地平线雾霭、程序化云带；进入时保存并设置这些全局渲染状态，退出时**完整还原**（有自动化断言）。
- **细节模型**：长征五号构型（芯级 + 4 助推，含钟形喷管、环缝、隔热层拼缝与「中国航天 / CZ-5 / 嫦娥奔月 / 国旗」标识）、真桁架脐带塔、导流槽、总装厂房、低温罐区、水塔、围栏、灯杆；嫦娥（服务舱 + 着陆器 + 可展开太阳翼/天线，着陆器带展开国旗）。
- **环境**：海岸线 + 海面 + 沙滩 + 林带 + 远处设施；地球（贴图 + 云层 + 大气辉光）；月球（贴图作凹凸）；着陆点近景用**真实月面贴图的原生分辨率**铺球冠，边缘 alpha 淡出。
- **教学标注**：地月进度条、每个阶段的「为什么」讲解、转移椭圆的**速度箭头**（开普勒第二定律）、轨道线渐进揭示。

## 4. 界面与交互

### 4.1 桌面版

- **顶栏**：模块切换（全景/月相实验室/日月食/卫星）+ 复位/画质/全屏/帮助/关于/截图/书签/天象/二维码。
- **左下行星菜单**：一键定位（也可按 `0`–`8`、`M` 定位月球）。
- **底部时间条**：播放/暂停、倍速、单步、日期跳转、回到今天；倍速档位 `暂停 / 1秒=10分钟 / 1小时 / 6小时 / 12小时 / 1天`。
- **快捷键**：`空格` 播放暂停、`-`/`=` 调速、`[`/`]` 单步、`0-8`/`M` 定位、`L` 标签、`H` 隐藏界面、`R` 复位、`F1` 帮助。
- **其它**：手绘引导（首次）、书签（视角+时间+模块）、近期天象、截图分享、语音朗读、程序化背景音乐（Web Audio 生成，无音频文件）、「今晚月相」角标。

### 4.2 手机版（`mobile.html`）

触屏优先的独立入口：底部 4 个 Tab、顶部工具栏、时间条、星球条、捏合缩放与拖动旋转。
进入奔月任务时会**自动收起全部常驻 UI**（顶栏/标签/时间条/星球条/月相角标/提示），只留任务 HUD；竖屏会按镜头类型自动调整机位后退量（宽场景退得多、特写退得少）。

### 4.3 儿童模式

由 `src/ui/kid-mode.js` 驱动：放大字号、隐藏专业控件、把模块文案切换为儿童版（各模块内置 `*_KID` 文案表），模块无需重建。

## 5. 技术架构

### 5.1 目录结构

```
solar-system/
├─ index.html            桌面入口（UI 骨架 + 各面板 DOM）
├─ mobile.html           手机入口
├─ src/
│  ├─ main.js            桌面主控：启动、场景、模块切换、渲染循环、全局交互
│  ├─ mobile-main.js     手机主控（复用同一套 sim/scene/modules）
│  ├─ config.js          天体常量、比例因子、快捷键映射、聚焦顺序
│  ├─ sim/               与渲染无关的模拟层
│  │   ├─ clock.js       历书时钟（JD，暂停/倍速/单步/跳转）
│  │   ├─ astro.js       astronomy-engine 封装：EQJ→黄道系场景坐标（AU），日月食与月相判定
│  │   ├─ camera.js      OrbitControls 封装：定位/跟随/复位/机位预设/距离钳制
│  │   ├─ quality.js     画质档（pixelRatio/星场数/细节）+ 启动自动选档 + 运行时降档
│  │   ├─ timeutil.js    JD ↔ Date
│  │   └─ bus.js         极简事件总线（UI ↔ 模拟 ↔ 场景 解耦）
│  ├─ scene/             可视化构建
│  │   ├─ build-system.js 组装太阳系场景
│  │   ├─ planet.js / sun.js / rings.js / atmosphere.js / starfield.js / orbits.js / labels.js
│  │   ├─ texture-store.js      贴图缓存 + 降级链（真实贴图 → 程序化回退）
│  │   └─ procedural-textures.js 程序化回退贴图
│  ├─ modules/           四个教学模块 + 电影模块
│  │   ├─ module-base.js  生命周期基类（enter/exit/update/render/disposeScene）
│  │   ├─ orbit-view.js / moon-phases.js / eclipse.js / satellite.js
│  │   └─ lunar-mission.js 嫦娥奔月（独立电影模块）
│  ├─ ui/                17 个界面组件 + ui.css（顶栏/时间/缩放/资料/书签/天象/二维码/截图/语音/音乐/儿童模式/帮助/引导/WebGL 兜底…）
│  ├─ data/planet-facts.js 行星中文科普资料（课堂版 + 儿童版）
│  └─ mobile/mobile.css  手机端样式
├─ public/textures/      12 个真实贴图（2K 太阳/行星/月球/地球云/土星环）
├─ public/sw.js          Service Worker（手机端离线缓存，Cache-First，缓存名 ss-v3）
├─ scripts/              构建服务 + 各类自检脚本（见第 8 节）
├─ tests/                单元测试（6 个文件 / 28 项）
├─ docs/                 全部文档（见第 11 节）
└─ demos/                早期独立原型（lunar-orbiter）
```

### 5.2 数据流

```
Clock(JD) ──► astro(astronomy-engine) ──► 天体位置/姿态
                    │
                    ├─► scene/*（行星、轨道线、标签、星场）
                    └─► modules/*（教学模块 / 电影模块）
                                     │
UI(ui/*) ──bus.emit/on──► 模拟与场景（模块切换、时间控制、选择天体）
```

模块之间**不直接互相调用**，统一通过 `src/sim/bus.js` 的事件解耦；模块切换由 `module.switch` 事件驱动（模块内部不在 `exit` 里发事件，避免递归切换）。

### 5.3 关键设计决策

| 决策 | 原因 |
| --- | --- |
| 电影模块自带独立场景与比例尺 | 太阳系是 AU 尺度，火箭相对地球小到不可见；电影需要另一套自洽的「示意比例」才能同时看清火箭与地球 |
| 贴图**降级链**（真实 → 程序化） | 任何贴图缺失/加载失败时绝不出现光秃纯色球（e2e 有专项断言） |
| 画质档 + 软件渲染检测 | 无独显的教室电脑自动降到低档；运行中持续降帧也会自动降档 |
| WebGL 上下文丢失兜底 | `ui/gl-guard.js` 弹出恢复提示，避免课堂中途白屏 |
| 全局渲染状态「谁改谁还原」 | 电影模块改 ACES/阴影，退出必须还原（`verify-lunar` 有断言） |

## 6. 天文与物理的正确性

- **行星/月球位置**：`astronomy-engine`（真实历表），场景坐标为黄道系 AU，含帧缓存。
- **月相**：由太阳—地球—月球几何关系计算照亮比例与相位角。
- **日月食**：结合月球轨道倾角与交点判定，可跳转到真实事件时间。
- **奔月转移轨道**：椭圆轨道由**平近点角解开普勒方程**求真近点角（`_kepler` / `_nuFromM`），保证「近快远慢」，与画面中的速度箭头（`v=√(2/r−1/a)`）一致。
  > 早期版本直接让真近点角随时间线性变化，导致远地点反而最快、与速度箭头自相矛盾——已修正。

### 8.2 视觉自检台（本项目特有）

只用数值断言无法发现「画面里全是柱子」这类问题，因此配了一套**看图验收**的工具：

| 命令 | 作用 | 产物 |
| --- | --- | --- |
| `npm run test:vision` | 12 个阶段 × 7 个机位（导演机位 + 每 60° 环绕）定格拍摄，附像素统计与接触表 | `shots/sheet_*.png`、`shots/report.json` |
| `npm run test:strip -- <阶段> [帧数]` | 把某阶段按时间等分采样拼成「胶片」，用来判断**节奏**（静止截图看不出快慢） | `shots/strip_<阶段>.png` |
| `npm run test:run [间隔ms]` | 不干预跑完整片，定期抓帧拼总览 + **阶段切换跳变检测**（孤立尖峰）+ 各阶段真实耗时 | `shots/fullrun.png`、`fullrun.json` |
| `npm run test:perf` | 逐阶段测帧时间 / draw call / 三角形数（默认走真实 GPU，`SW=1` 走软件渲染） | 控制台 |
| `PAGE=mobile.html DIST=dist` 配合 `test:run` | 手机竖屏整片连拍 | `shots-mobile/fullrun.png` |

页面侧提供 QA API：`qaGoto(phase, frac)`（定格到某阶段并预热状态）、`qaCam(pos,tgt,up)`（接管相机）、`qaRelease()`；`window.__SS.textureProgress()` 用于等待贴图就绪。

实测性能（Intel Iris Plus 集显 / 1280×720）：各阶段 **56–61 fps**（受 vsync 限制），draw call 21–163，任务启动约 180 ms。

> 详细用法与 5 个已知坑见 `docs/视觉自检台.md`。

## 12. 已知限制与后续可做

**已实现但与「真实比例」有关的取舍（不是 bug）**

- 太阳系场景有「教学比例 / 完全真实比例」两档；教学比例下行星被放大，否则行星在屏幕上只有亚像素。
- 奔月模块用的是**示意比例尺**（火箭相对地球被放大约几个数量级），目的是同框可见；页面里的速度箭头、轨道形状等物理量仍是正确的。

**已知小问题 / 可继续改进**

- `test:e2e` 偶发一次 81/82（出现在紧接重度视觉自检之后，疑似负载导致的时序抖动；随后连跑三次均 82/82），具体是哪一项未复现。
- 发射场从低角度侧看仍偏空旷（已有海岸线/林带/远景设施，但近景细节可以再加）。
- 转移段深空巡航的时长与卫星近景细节、着陆点近景的碎石分布，都还有打磨空间。
- 月球轨道段的卫星模型细节（多层隔热毡褶皱、天线馈源）在极近景下还能更细。
