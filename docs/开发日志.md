## 收尾轮 5 记录（2026-09-06 · 标签开关 bug 修复 + 显隐开关 UX）
用户反馈需要"控制星球标签显隐"的开关。排查发现**原有标签开关实际是坏的**：
- 根因：天体标签是 CSS2D 对象，`orbit-view._updateLabels()` 原先用 `element.style.display` 控制显隐，但 Three.js 的 CSS2DRenderer 每帧会**按 object.visible 重置 display**，导致改样式被覆盖、开关完全失效（点击前后标签始终 9 个可见）。
- 修复：`_updateLabels()` 改为切换 `object.visible`（`obj.visible = labelsVisible && !hidden`），这才是 CSS2D 隐藏的正确方式。
- UX 增强：右上角"标签"按钮改为显式状态——"标签·开 / 标签·关"，关闭时按钮变暗（`.icon-btn.off`）；快捷键 **L** 同步可用。
- 手机端：手机版也共用同一 OrbitView，此前没有标签开关；已在手机顶栏新增"标签"按钮（`#m-label`，点击切换+状态 .off），并压缩顶栏间距（gap 4 / 按钮 padding 8 / 品牌 13px）使 7 个按钮在 390px 内全部可见不溢出。
- 验证：单测 12/12；桌面 e2e 47/47；手机顶栏 scrollW==390 全部可见；标签开关点击前后 9→0 个标签，按钮状态同步，L 键可用。双端产物已重建。
- 说明：e2e 在高负载下偶发超时（软件渲染慢），单独复跑通过，非代码问题。

用户反馈：切到"完全真实比例"后，太阳变得无比小（一个像素级黑点）。

## 收尾轮 7 记录（2026-09-06 · 真实比例可用化 + 月地功能澄清 + 距离核对）
用户反馈三点：
1. **"完全真实比例"下天体几乎不可见，不实用** → 重做为"真实距离比例"：
